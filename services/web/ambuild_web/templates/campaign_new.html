What goes in a campaign
  • parameters: each {"name", "path", "type": "float" | "int" | "choice", "low", "high", "log"} or "choices": [...]; "all": true sets every element of a list.
  • constraints: each {"metric", "min", "max"}; objective: {"maximise": metric}, {"minimise": metric} or {"target": {"metric", "value"}}. Metrics: {{ metrics | join(", ") }}.
  • replicates (seeds per point, default 3), feasible_fraction (of a point's seeds that must meet a constraint, default 0.5), method ({{ methods | join(", ") }}; external: points come from outside, e.g. an LLM agent or a person), initial_points, batch_size (points per round), budget {"runs"}, stop {"feasible_points", "no_improvement_rounds", "max_rounds"}.
