Building blocks and parameter files

Each fragment needs its .car file and the .csv that defines its end groups. Files are stored once, by content. Select a placeholder in the recipe, then press Insert to put a file's reference there.

Recipe reference

Top level: recipe_version ({{ format.recipe_version }}), name, cell (box in Å; atom_margin, bond_margin, bond_angle_margin), fragments (type, car, csv, optional ambody, name, solvent, catalyst, mark_bonded), params (null for the standard files, or references for {{ format.params_files | join(", ") }}), bond_types, max_bonds, stages, seed. A stage is {"op": …, arguments} or {"repeat": n, "stages": […]}; a checkpoint (pickle and structure) is written after each top-level stage and each pass of a top-level repeat.
